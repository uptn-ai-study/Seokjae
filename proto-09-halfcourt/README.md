# HALF COURT — 반코트 2v2 스트리트볼 축구

골대 하나를 양 팀이 함께 공략하는 **연속 턴오버(스트리트볼) 룰** 모바일 캐주얼 축구.
**단일 `index.html`** · 외부 의존성 없음 · Canvas 2D.

## 핵심 룰 — 클리어 & 턴오버
- 전·후반 고정 공수 없음. **공을 가진 팀이 공격, 빼앗긴 팀이 수비** (소유권으로 실시간 결정).
- 공을 새로 얻으면(스틸·태클·세이브/빗맞은 슛 리바운드·루스볼 선점) 곧바로 공격할 수 없고,
  하단 **클리어 라인(점선) 아래로 공을 빼야** 공격이 허용됩니다 → 스틸→역습→득점의 리듬.
- 제한 시간 동안 **더 많이 넣는 팀 승**. 득점하면 실점 팀이 공을 갖고 재개(역전 기회).

## 플레이 방법
- 노란 링 + 셰브론이 붙은 선수가 **당신**. 컨트롤은 항상 **우리 팀 볼 보유자 / (수비 시) 공에 가까운 선수**로 자동 전환됩니다.
- **공격** — 빈 곳 탭/스와이프=드리블, **동료 탭=패스**, **위로 스와이프=슛**(클리어 후 공격구역에서만).
- **수비** — 상대 볼 보유자에 **근접 후 탭/스와이프=태클**, **동료 탭=수비 선수 전환**, 빈 곳 탭=이동.
- 루스볼은 **양 팀 모두** 먼저 닿는 선수가 차지 → 스크램블 쟁탈전.

## 동작 특징
| 영역 | 구현 |
|---|---|
| 조작 | 탭/스와이프 3단계 판별, 공수에 따라 제스처 의미 전환, 컨트롤 자동 스위치 + 수동 전환 |
| 슛 판정 | `P(골)=존기본값 × 스와이프정확도 × 압박계수`(R=120px, 존별 80/50/22%), 근거리 컨테스트 슛 허용 |
| AI(상대) | 클리어→공간 드리블(막히면 빈 포스트로 침투)→오픈/근거리 슛, 동적 오프더볼(마커 떨치기·런·오버랩) |
| AI(수비) | 떨어져서 컨테인(들러붙기 최소화) + 마킹/패스레인 차단, 능동 태클, 미클리어 시 리트리트 |
| 긴박감 | 30초 전 주황·10초 전 적색 펄스 테두리, 5초 대형 카운트다운, 골 시 화면 흔들림·플래시·색종이 |
| 비주얼 | 잔디 그라데이션+모우 스트라이프+비네트, 접지 그림자, 그라데이션 선수(이동 방향 기울임), 트레일 달린 공 |
| 오디오 | Web Audio API 절차적 음향(킥/골/세이브/휘슬/가변 BPM 드럼), Vibration API 햅틱 |
