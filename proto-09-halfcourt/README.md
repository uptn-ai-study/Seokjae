# HALF COURT — 반코트 2v2 축구

GDD v1.0 기반 모바일 캐주얼 축구 게임. **단일 `index.html`** · 외부 의존성 없음 · Canvas 2D.

## 플레이 방법
- **빈 곳 탭** → 드리블/이동
- **동료 탭** → 패스
- **위로 스와이프(↑)** → 슛 (스와이프 길이 = 파워, 골대 정면일수록 성공률↑)
- **옆/아래 스와이프** → 그 방향으로 드리블
- 노란 링이 표시된 코랄색 선수가 **당신**입니다.

전반엔 공격, 후반엔 역할이 교대되어 수비합니다. 양 반(half) 누적 득점으로 승부를 가립니다.

## 구현된 GDD 시스템
| GDD 항목 | 구현 |
|---|---|
| §2 조작 체계 | 탭/스와이프 3단계 판별, 슛 쿨다운 0.6s, 공격구역 밖 슛→드리블 변환 |
| §3 슛 판정 | `P(골)=존기본값 × 스와이프정확도 × 압박계수`, 압박계수 `1-(0.7·f(d1)+0.3·f(d2))`, R=120px, 존별 80/50/22%, 최솟값 보정 |
| §4 루스볼 | 탈취 벡터 + ±25° 편차, 감속 ×0.91/frame, 카운트다운(20초 옵션=2s/그 외 3s), 페널티 안/밖 리셋 위치 분기 |
| §5 AI | 동료(SUPPORT/RECEIVE/RECOVER/SHOOT_ONCE, 전반 슛 2회 제한·종료임박 해제), 수비(Intercept/Mark/Block, 시간연동 난이도) |
| §6 흐름 | 타이틀→전반→하프타임→후반→결과, 시간옵션 20초/1분/3분 |

| §7 비주얼 | 페이퍼컷(색면+drop-shadow), 회전하는 오각형 음영 공 |
| §7.2 오디오 | Web Audio API 절차적 음향(킥/골/세이브/휘슬/가변 BPM 드럼), Vibration API 햅틱 |
