# ⚾ Batting Practice

포수·심판 시점에서 MLB 타석을 체험하는 배팅 연습 웹앱

## 플레이 방법

- **PC**: 화면 클릭으로 스윙
- **모바일**: 탭(센터), 위 스와이프(당겨치기), 아래 스와이프(밀어치기)
- 공이 날아오는 타이밍에 맞춰 스윙하면 HIT!

## 기능

- 4가지 화면: 설정 → 배팅 → 타구 결과 → 세션 종료
- 최고 구속 100~160 km/h 슬라이더 설정
- 7가지 구종(직구·투심·커터·슬라이더·커브·체인지업·스플리터) 선택
- 구종별 궤적 차이 (커브 낙차, 슬라이더 횡변화, 스플리터 급락 등)
- 스트라이크 존 9분할 격자 + 공 낙하 셀 하이라이트
- 탑뷰 야구장 타구 궤적 애니메이션 + 비거리 계산
- 10타석 후 타율·최장비거리·최다방향 통계

## 기술 스택

Vanilla JS + Canvas API · 외부 라이브러리 없음 · 단일 HTML 파일
