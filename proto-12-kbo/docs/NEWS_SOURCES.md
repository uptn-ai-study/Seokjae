# 뉴스 심리 분석 — 참고 언론사 & 방법

## 개요

경기 데이터의 **최신 경기일(as-of)을 기준으로 최근 3일간**의 KBO 관련 기사를 팀별로
수집해, 긍정/부정 감성을 점수화하고 "뉴스로 본 순위"와 "다음 경기 예측(실험적)"을 만든다.

- 수집: **구글 뉴스 RSS** (`news.google.com/rss/search`, `hl=ko&gl=KR&ceid=KR:ko`)
  - 팀별 검색어 = `<정식 구단명> 야구`, 기간 `after:/before:` 로 as-of 기준 3일 창.
  - `<source>`(언론사명)로 **아래 주요 언론사 allowlist** 만 남기고 블로그·아그리게이터
    (Naver Blog, v.daum.net 등)·커뮤니티는 제외.
  - `pubDate` 로 창 밖 기사를 재필터. 제목 중복 기사는 1건으로 합침.
- 감성: **사전(lexicon) 기반** — 제목+요약에서 긍정/부정 키워드 등장 수를 센다
  (`scripts/news/sentiment.mjs`). 다어절 표현 우선 매칭으로 `역전승`(＋)과 `역전패`(−)를 구분.
- **단일 팀 기사만 집계**: 기사 본문에서 언급된 KBO 팀을 감지(`build_news.mjs`의
  `TEAM_ALIASES`)해, **한 팀만 언급된 기사**만 그 팀의 긍정/부정으로 센다. **여러 팀이 함께
  언급된 기사**(주로 경기 리뷰)는 어느 팀의 호재/악재인지 사전만으로 판별할 수 없으므로
  **중립(참고)으로 분류하고 점수에서 제외**한다.

## ⚠ 한계 (반드시 인지)

- 사전 기반 감성은 **문맥·반어를 모른다.** (예: 인용된 부정 표현, 비꼬는 제목)
- 단일 팀 필터로 "경기 리뷰가 양 팀에 잡혀 승자 키워드가 패자에 반영되는" 문제는 완화했지만,
  그 대신 **승패가 명확한 리뷰 기사는 대부분 중립으로 빠져** 뉴스 표본이 줄어든다.
  → 승패 신호는 순위·최근 폼(경기 기록)이 담당하고, 뉴스는 **부상·이탈·개인 활약·로스터 등
  팀 고유 서사**를 반영하는 역할로 나뉜다.
- 팀 감지는 별칭 부분 매칭이라 오검출 시 **중립으로 빠지는 안전한 방향**으로 기운다.
- 따라서 점수·순위·예측은 **정확한 감정이나 승부 예측이 아니라 재미로 보는 실험적 지표**다.
  더 정교하게 하려면 개체(팀)별 문맥을 이해하는 **LLM 기반 감성 분석**이 필요하다
  (현재는 사용자 선택에 따라 무료·무키 사전 방식 채택).

## 저작권

기사 저작권은 각 언론사에 있다. 본 프로젝트는 **비상업적/학습용**으로 제목·출처·링크만
인용하며 원문 전체를 저장하지 않는다.

## 실행

```bash
npm run data:news       # 뉴스 심리만 갱신 (news/<season>.json)
npm run data:update     # 전체(경기+선수+뉴스) 일일 갱신에 포함됨
```
