# 뉴스 심리 분석 — 참고 언론사 & 방법

## 개요

경기 데이터의 **최신 경기일(as-of)을 기준으로 최근 3일간**의 KBO 관련 기사를 팀별로
수집해, 긍정/부정 감성을 점수화하고 "뉴스로 본 순위"와 "다음 경기 예측(실험적)"을 만든다.

- 수집: **구글 뉴스 RSS** (`news.google.com/rss/search`, `hl=ko&gl=KR&ceid=KR:ko`)
  - 팀별 검색어 = `<정식 구단명> 야구`, 기간 `after:/before:` 로 as-of 기준 3일 창.
  - `<source>`(언론사명)로 **아래 주요 언론사 allowlist** 만 남기고 블로그·아그리게이터
    (Naver Blog, v.daum.net 등)·커뮤니티는 제외.
  - `pubDate` 로 창 밖 기사를 재필터. 제목 중복 기사는 1건으로 합침.
- 감성: **교체식 provider**(`scripts/news/providers.mjs`). 팀 감지는 공용
  `scripts/news/teams_detect.mjs`(`TEAM_ALIASES`).

### 감성 provider (2가지, 자동 선택)

| provider | 선택 조건 | 방식 | 여러 팀 기사 |
| --- | --- | --- | --- |
| **nvidia (Gemma 4)** | `NVIDIA_API_KEY` 있음 | NVIDIA NIM 의 `google/gemma-4-31b-it` 로 **기사별 각 구단 관점** 호재/악재를 판정 (한국어 강점) | 팀마다 다르게 집계(이긴 팀 호재·진 팀 악재) |
| **lexicon (사전)** | 키 없음 / API 실패 시 폴백 | 제목+요약 긍정/부정 키워드 카운트(`sentiment.mjs`) | **단일 팀 기사만 집계**, 여러 팀 기사는 중립(참고)으로 제외 |

> **모델 선택(2026-07 무료 엔드포인트 실측):** Qwen 3.5(`qwen/qwen3.5-397b-a17b`)는 목록엔 있으나
> 추론이 404(미서빙), Qwen3-Next-80B·Llama-3.3-70B는 타임아웃, DeepSeek V4는 503(과부하)이었다.
> **`google/gemma-4-31b-it` 만이 빠르고(≈5초) 정확한 한국어 팀별 JSON 판정**을 안정적으로 냈다.
> `NVIDIA_MODEL` 환경변수로 다른 모델로 교체할 수 있다(추후 Qwen 서빙 시 등).

- 무키·무료로도 동작하며, `NVIDIA_API_KEY`(NVIDIA build 무료 키)만 넣으면 Qwen 맥락 분석으로
  자동 업그레이드된다. Qwen 호출 실패 시에도 파이프라인은 사전 방식으로 폴백해 깨지지 않는다.
- Qwen 호출은 기사 8건씩 배치 + 요청 간 1.5초 지연 + 429/5xx 재시도로 40 RPM 무료 한도를 지킨다.
  하루 고유 기사 ~80~150건 → ~10~20콜, 토큰 사용량 극소.

### NVIDIA(Qwen) 키 설정

1. [build.nvidia.com](https://build.nvidia.com/models) 에서 무료 API 키 발급(신용카드 불필요).
2. 로컬: `cp .env.example .env` 후 `.env` 에 `NVIDIA_API_KEY=nvapi-...` 입력(‥`.env` 는 git 제외).
3. 실행: `npm run data:news`. 로그에 `감성 provider: nvidia:google/gemma-4-31b-it` 가 뜨면 성공.
4. 자동 갱신: GitHub 저장소 **Settings → Secrets → Actions** 에 `NVIDIA_API_KEY` 등록
   (워크플로가 `secrets.NVIDIA_API_KEY` 로 전달). 없으면 CI 는 사전 방식으로 돈다.

## ⚠ 한계 (반드시 인지)

- **사전(lexicon) 방식**은 문맥·반어를 모르고, 여러 팀 기사를 중립으로 빼므로 뉴스 표본이 줄어든다.
  승패 신호는 순위·최근 폼(경기 기록)이 담당하고, 뉴스는 부상·이탈·개인 활약 등 팀 고유 서사를 반영.
- **Qwen 방식**은 팀별 맥락을 이해해 여러 팀 기사도 팀마다 판정하지만, 여전히 자동 분석이라
  오분류가 있을 수 있다. 팀 감지 별칭이 후보를 좁히고, 모델은 그 후보 팀에 대해서만 판정한다.
- 어느 방식이든 점수·순위·예측은 **정확한 감정이나 승부 예측이 아니라 참고용 실험 지표**다.

## 저작권

기사 저작권은 각 언론사에 있다. 본 프로젝트는 **비상업적/학습용**으로 제목·출처·링크만
인용하며 원문 전체를 저장하지 않는다.

## 실행

```bash
npm run data:news       # 뉴스 심리만 갱신 (news/<season>.json)
npm run data:update     # 전체(경기+선수+뉴스) 일일 갱신에 포함됨
```
